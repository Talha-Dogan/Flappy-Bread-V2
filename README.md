# Flappy Bread 2 🍞

![Version](https://img.shields.io/badge/version-2.0-blue)
![Engine](https://img.shields.io/badge/Made%20with-Unity-black)


> The crispy sequel to the original Flappy Bread! Now with smarter enemies and a global leaderboard.

## 🎮 About The Game

Flappy Bread 2 takes the classic "tap-to-fly" mechanic and adds a bakery twist. You play as a slice of bread trying to escape hungry dogs in an endless runner setting. 

This repository contains the source code for the **Version 2** update, which introduces major mechanic overhauls and a competitive leaderboard system.

### 🔗 Play Online
Play the game directly in your browser on Itch.io:
- **[Play Flappy Bread 2](https://talha-dogan.itch.io/flappy-bread2)**
- [Original Version (Legacy)](https://talha-dogan.itch.io/flappy-bread)

## ✨ Key Features

* **Endless Runner Mechanics:** Physics-based jumping logic.
* **Global Leaderboard:** Compete with players worldwide using the new scoring system.
* **Dynamic Obstacles:** Dogs and environmental hazards that require quick reflexes.
* **Updated UI:** A cleaner, more responsive user interface compared to V1.

## 🛠️ Built With

* **Engine:** Unity 2021.3.29
* **Language:** C#
